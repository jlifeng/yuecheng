## 1. 入驻申请

首次以商家身份使用，需先提交入驻申请：

1. 在「我的」切换到商家模式，进入入驻申请页。
2. 选择入驻类型：
   - **个人司机**：需驾驶证和车辆。
   - **企业车队**：需营业执照。
3. 填写：公司名称（企业）/ 联系人姓名 / 联系电话 / 简介。
4. 上传资质材料（营业执照、车辆照片等，按提示）。
5. 提交申请。

**审核**：平台在 **1-3 个工作日**内审核。审核期间工作台显示「审核中」，**无法报价接单**。通过后状态变为「已认证」，即可正常经营。

> 若被拒绝，按提示修改资料后重新提交。

## 2. 工作台总览

商家首页即「接单工作台」，顶部三个 Tab：

| Tab | 内容 |
|-----|------|
| **待报价需求** | 乘客刚发布、待报价的需求大厅（已有他人报价的需求不会出现） |
| **已报价** | 你已提交报价、等待乘客选单的需求 |
| **进行中** | 乘客已选你、正在履约的订单 |

顶部可按**城市筛选**，或切换「全国」看全部。审核状态会在顶部以卡片提示（审核中 / 已认证 / 未通过）。

下拉可刷新列表。

> 重要：**独占报价机制**——同一需求同一时间只允许一个司机提交报价（状态为「待报价」时）。只要该需求已存在一条「待处理」报价，就不会再出现在其他司机的工作台。只有当报价被乘客拒绝、或被取消后，该需求才会重新开放给其他人报价。

## 3. 报价接单

1. 在「待报价需求」点击某条需求，查看详情（起终点、时间、人数、备注）。
2. 点击 **「填写报价」** 进入报价页。
3. 选择车辆（从本车队已添加的车辆中选）。
4. 输入报价金额。
5. 填写报价说明（可选，如车型亮点、服务承诺）。
6. 点击 **「确认报价」** 提交。

报价后该需求进入「已报价」Tab，等待乘客选择。

> 提示：
> - 报价金额、车型、说明都会展示给乘客，越清晰越容易被选中。
> - **报价人即执行司机**——一旦乘客选中你的报价，你本人就是这单的执行司机，无需再指派。
> - 如果该需求已被其他司机抢先报价，你将看不到该需求，也无法重复报价。

## 4. 履约节点推进

当乘客选中你的报价，订单进入「进行中」Tab。**你本人即执行司机，无需指派环节**。订单详情页会根据当前状态显示**唯一的主操作按钮**：

| 当前状态 | 主操作按钮 | 何时点 |
|----------|-----------|--------|
| 待出发 | **去接驾** | 你出发前往上车点 |
| 去接驾中 | **到达上车点** | 抵达接客地点 |
| 已到达上车点 | **乘客已上车** | 乘客上车，行程开始 |
| 行程中 | **到达目的地** | 抵达终点 |

> 首次点击「去接驾」时，系统会自动把你关联为本订单的执行司机（如尚未关联）。

每点一次主操作，状态前进一格，乘客侧时间线同步更新，系统自动记录事件。

> 规则：
> - 只能**按顺序一步步推进**，不能跳步（如不能从「待出发」直接点「到达目的地」）。
> - 乘客可在详情页实时看到每一步进度。
> - 每次推进都会留档，便于事后核查。
> - 只有执行司机本人能推进履约节点，其他司机只能查看进度。

## 5. 录入费用

**到达目的地**后，进入费用环节：

1. 订单详情页主按钮变为 **「提交费用」**，点击打开费用表单。
2. 填写明细：
   - **基础车费**（默认填你的报价金额，可改）
   - **过路费 / 停车费 / 其他费用**（按实际填写，没有则留 0）
   - 备注（可选）
3. 如全程无任何附加费，直接点 **「无附加费提交」**。
4. 提交后状态变为 **待确认费用**，等待乘客确认。

乘客确认后，订单状态变为 **已完成**。

> 重要：
> - 悦途**不在线收款**，所有费用**线下与乘客结算**。这里录入的费用仅作**留档**，供双方日后查账与开票参考。
> - 一旦提交费用，**订单不可再取消**；乘客也只能确认或协商，不能改金额。提交前请核对无误。
> - 提交后到乘客确认前，你仍可修改费用明细（重新提交）。

---

## 6. 取消订单

在**提交费用之前**，若行程无法继续（如联系不上乘客、车辆故障），可取消：

1. 订单详情页点击 **「取消订单」**。
2. 选择取消原因（乘客取消 / 车辆故障 / 无法联系乘客 / 其他）。
3. 确认取消。

> 注意：**已提交费用（待确认费用）后不能再取消**，需与乘客协商解决。

## 7. 车队与司机管理

在「我的」可进入：

- **我的车队**：维护车辆信息（车牌、车型、座位数、颜色、保险日期、照片）。
- **司机管理**：维护司机档案（姓名、手机号、在岗状态、关联车辆）。

只有**审核通过**的商家可管理。司机添加后，会被邀请加入车队，司机本人确认后即可在工作台自行报价接单。

> 提示：司机手机号用于邀请关联——队长录入司机手机号后，该用户用此手机号登录并在「我的」确认加入，即自动关联到车队，并获得司机角色。

## 8. 我的订单与个人中心

底部 Tab「我的」：

- **我的订单**：查看全部历史订单（进行中 / 已完成 / 已取消）。
- **我的车队 / 司机管理**：见上节。
- **个人资料**：点击昵称可手动输入设置；点击头像可设置头像。
- **退出登录**：底部可切换账号或退出。

## 9. 司机角色说明

若你的账号被车队队长添加并**确认加入**车队，你会同时拥有**乘客 + 司机**两个角色：

- **保留乘客身份**：你仍可在乘客端发布需求、查看自己的行程。
- **新增司机身份**：可进入商家工作台，像商家一样浏览需求并**自行报价接单**。
- 工作台 Tab 文案变为：**今日任务 / 当前订单 / 服务记录**。
- 在「我的」可看到所属车队信息和待确认的车队邀请。
- 报价被乘客选中后，你即为本订单执行司机，按第 4 节推进履约。

> 司机不能独立入驻，必须由车队队长添加。确认加入后无需指派环节，自己接单自己执行。

## 常见问题

**Q：审核要多久？审核中能接单吗？**
A：1-3 个工作日。审核中**不能报价、不能接单**，工作台会提示「审核中」。

**Q：为什么我看中的需求点不进去/报不了价？**
A：该需求已被其他司机抢先报价（独占报价机制）。只有当那条报价被乘客拒绝、或被取消后，需求才会重新出现在待报价列表。

**Q：报价后乘客没选我，怎么办？**
A：正常现象，乘客会多家比价。可优化报价金额、车型和说明提高中标率。未选中的报价不影响你继续接其他需求。

**Q：接单后还要指派司机吗？**
A：**不需要**。报价人即执行司机，乘客选中你的报价后你本人就是本单司机。直接点「去接驾」开始履约即可。

**Q：我不是报价人，能操作订单吗？**
A：不能。只有被选中的报价人本人才能推进履约节点，其他司机只能查看进度。

**Q：费用填错了，乘客还没确认，能改吗？**
A：能。在「待确认费用」状态重新提交费用即可覆盖。

**Q：乘客一直不确认费用怎么办？**
A：先线下沟通确认。费用记录已留档，不影响你后续接单。

**Q：司机怎么加入车队？**
A：队长在司机管理录入你的手机号后，你用该手机号登录小程序，在「我的」页面会看到车队邀请卡片，点击「确认加入」即可。

**Q：我同时是乘客和司机，会不会冲突？**
A：不会。两个角色独立共存——你发布的乘客需求和接到的司机订单互不影响，在首页可切换查看。

**Q：线下收了钱，要在系统里做什么吗？**
A：系统不收款，但请务必**录入并确认费用**，作为双方交易留档，便于售后与开票。
